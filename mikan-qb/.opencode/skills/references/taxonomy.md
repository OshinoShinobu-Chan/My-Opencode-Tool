# 标签词典与语言判定

来源：`packages/mikan-qb/config.toml` 的 `[taxonomy]`，默认值与 `mikan_health.core.taxonomy` 保持一致（测试会校验是否漂移）。改词典只需改 `config.toml`，不必改代码。

## 词表

| 类别 | 默认标记 |
| --- | --- |
| 简体 | `简体` `简中` `简` `CHS` `GB` |
| 繁体 | `繁体` `繁中` `繁` `CHT` `BIG5` |
| 日语 | `日语` `日文` `JP` `JPN` |
| 简繁日 / 简日 | `简繁日` `简日繁` `简日` `繁日` `JPSC` `JPTC` |
| 内封/外挂（软字幕） | `内封` `外挂` |
| 内嵌/内挂（硬字幕） | `内嵌` `内挂` |
| 默认语言 | `繁体` |
| 生肉标记 | `raw` `raws` `生肉` `无字幕` `無字幕` `无字幕版` `no sub` `nosub` `无sub` |
| 排除词 | `合集` `BDRip` `全卷` `Fin` `NCOP` `NCED` `PV` `Menu` `Fonts` `字体` `SP` `OVA` |
| 打包正则 | `\[\d{1,3}\s*[-~—]\s*\d{1,3}\]`、`\d{1,3}\s*[-~—]\s*\d{1,3}\s*(?:TV)?全集`、`\[(?:TV)?全集\]`、`\[(?:完)\]` |

## 语言判定优先级（`language_source`）

1. 标题里**显式**出现简体/繁体/简日等标记 → `explicit`。
2. 出现生肉标记 → `raw`（判为无字幕 / 生肉）。
3. 都没有 → 按 `default_language` 推断，默认**繁体** → `inferred`。

## 下游如何区分对待（重要）

| 消费方 | 是否采用「推断的繁体」 | 原因 |
| --- | --- | --- |
| 语言展示、`has_traditional` | 是 | 便于人看，符合「没写就当繁体」的直觉 |
| **相对速度基线** `subtitle_baseline` | **否**（只认 `explicit`） | 未标注条目里混着生肉，算进基线会把正片组算成「慢好几天」 |
| **生肉剔除**（`rank` 资格过滤） | **否**（要求 `explicit` 中文） | 真正的生肉往往没有任何标记，只能靠「有没有显式中文字幕」拦住 |

因此很多组名不带语言标签但实际是繁体/简繁内封（如 `[LoliHouse] … [WebRip 1080p HEVC-10bit AAC ASSx2]`，`ASSx2` 是简繁两条字幕轨）：一律当无字幕会误杀，所以用「推断繁体」展示，但速度/资格仍只认显式标记。

**已知代价**：`[黒ネズミたち]`、`[H-Enc]` 这类无任何标记的生肉会被推断成繁体，语言列显示不准确；它们仍会被 `rank` 拦下。要减少误判，往 `raw_markers` 补标记词。

## 其他解析字段

`Resolution`（如 1080p）、`Codec`、`bit_depth`、`source_tag`、`is_dual_zh_jp`、`has_japanese`、`episode_raw`、`is_pack`、`is_extra`。

## 调试命令

```bash
uv run mikan tag parse "[桜都字幕组] 无职转生 第三季 [12][1080P][简繁内封]" --json
```

输出上述全部字段，用来核对某个标题被判成什么语言、是否打包。
